# Changelog

All notable changes to Pulse are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and versions
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Pulse is
still in `0.x`, so any release may change things.

## How this file is kept

- **Unreleased** is written by hand. Each pull request with a user-facing
  change adds one line under **Added**, **Changed**, **Fixed**, **Removed**
  or **Security**.
- **Released versions** are generated by `python3 scripts/changelog.py`
  after each release, from the GitHub release notes. Those notes are the
  titles of the merged pull requests, in Spanish, exactly as the app shows
  them when it updates. They are kept verbatim and not sorted into
  categories after the fact.
- Versions come from git tags (`vX.Y.Z`), created by `scripts/release.sh`
  (see [docs/PUBLICAR.md](docs/PUBLICAR.md)).

## [Unreleased]

### Added

- Launch documentation: English `README.md` (Spanish in `README.es.md`),
  `CONTRIBUTING.md` in English (original Spanish kept in
  `CONTRIBUTING.es.md`), `docs/DOWNLOADS.md`, `docs/DEVELOPMENT.md`,
  `docs/FIRST_CONTRIBUTIONS.md`, `docs/PROJECT_MODEL.md`, `docs/ROADMAP.md`,
  `docs/GITHUB_COMMUNITY_SETUP.md`, `docs/DEMO_VIDEO_PLAN.md` and the launch
  audit and report.
- Community files: `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1),
  `SECURITY.md`, issue forms (bug, feature, plugin compatibility,
  installation/platform) and a pull request template.
- CI: macOS (Apple Silicon) workflow that builds and tests every pull
  request and packages an ad hoc-signed test build on `main`. Windows and
  macOS CI artifacts now include `SHA256SUMS.txt`.
- Interface language: **Ajustes › Idioma · Language** chooses Spanish or
  English, following the system's language by default. Translated so far:
  the menus, Settings, the "What would you like to do?" window, the
  transport bar, the browser with its search and favorites, the
  Arrangement, the Session, the devices (with their parameter names), the
  mix and master assistant, lessons, templates, factory presets and sounds,
  and key and chord names (with letters in English: "D minor", "Dm"); some
  editors and messages still show in Spanish.
- The user guide in English (`docs/guide.md`): Help › Pulse Guide shows it
  when the interface is in English. Both guides keep the same topics and
  headings, and the tests check it.

### Changed

- Windows CI: packaging, checksums, the render, the window start and the
  installer now run even when a test fails (the job still fails). Since
  2026-10-29 the failing tests had kept them from running at all. A failed
  window start now shows as a warning on the run's page.
- macOS CI: the test package is built even when a test fails, as on Windows.

### Fixed

- Audio to MIDI (Basic Pitch): the start of a note could move by one frame
  (≈12 ms) depending on the processor or the number of threads, when the
  largest jump and the onset peak fell on neighbouring frames. It's now the
  same on every machine.
- Windows CI packages carried the placeholder version `0.1.3`, because the
  checkout had no tags. They now get the real version.
- Two tests failed on Windows because their expected paths put a `/` inside
  one `Path::join` (`factory_sounds_tests`, `lyrics`). They now build the
  path part by part. Pulse's own behaviour was already right. They pass on
  macOS and on Windows CI (run 41808950553, 2026-11-04).
- Windows status docs said CI could not run and nothing had run on Windows.
  In fact CI built, tested, ran and installed Pulse on Windows in October
  2026 (last complete run: 2026-10-29).
